## 🚀 Uso

### Opción 1: Abrir directamente en navegador

```bash
open index.html
```

O simplemente haz doble clic en el archivo `index.html`.

### Opción 2: Usar servidor local

```bash
# Python 3
python3 -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (con npx)
npx http-server
```

Luego abre `http://localhost:8000` en tu navegador.

## 📦 Deployment

### GitHub Pages

1. Sube el archivo a un repositorio de GitHub
2. Ve a Settings → Pages
3. Selecciona la rama `main` y carpeta `/web`
4. Guarda y espera unos segundos
5. Tu página estará disponible en `https://usuario.github.io/repo/`

### Netlify

1. Arrastra la carpeta `web` a https://app.netlify.com/drop
2. Tu página estará disponible inmediatamente

### Vercel

```bash
npx vercel web/
```

### Tipografía Racing
- **Familia**: Impact, Arial Black (sans-serif bold)
- **Tamaño títulos**: 72px (desktop), 48px (tablet), 36px (mobile)
- **Tamaño contenido**: 32px (desktop), 24px (tablet), 18px (mobile)
- **Peso**: 900 (extra bold)
- **Letter-spacing**: 6-8px (espaciado amplio)
- **Transform**: uppercase + skew (efecto velocidad)
- **Efectos**: Text-shadow, neon glow, gradientes

### Categorías de Animaciones

#### Animaciones de Entrada
- `fadeInDown`: Logo racing aparece desde arriba
- `slideInLeft`: Botones entran desde la izquierda
- `slideInRight`: Títulos con efecto de velocidad
- `trophyRise`: Trofeo sube desde abajo
- `riseUp`: Podio sube secuencialmente
- `bounceIn`: Botones con rebote

#### Animaciones de Fondo
- `speedLines`: Líneas de velocidad en movimiento
- `speedMove`: Efecto de aceleración
- `roadLines`: Líneas de carretera
- `confettiFall`: Confetti cayendo

#### Animaciones Continuas (Loops)
- `pulse`: Efecto de pulso en elementos
- `wave`: Bandera ondeando
- `rotate`: Herramientas girando
- `trophyFloat`: Trofeo flotando
- `sparkleMove`: Destellos moviéndose
- `lightning`: Rayos parpadeando
- `goldShimmer`: Brillo dorado

#### Animaciones Interactivas
- `hover`: Transformación al pasar mouse
- `shine`: Brillo deslizante
- `timerBlink`: Parpadeo de números
- `neonFlicker`: Efecto neón parpadeante

### Layout System
- **Sistema base**: Flexbox + CSS Grid
- **Index**: Flexbox vertical centrado
- **Páginas internas**: Flexbox vertical con espaciado
- **Stats/Info**: CSS Grid 2-4 columnas
- **Podio**: Flexbox horizontal (alineado abajo)
