## 🎯 Tareas

### Tarea 1: Crear estructura HTML
**Descripción**: Crear archivo `index.html` con estructura básica
**Tiempo estimado**: 5 minutos
**Responsable**: Agente Desarrollador

**Subtareas**:
1. Crear archivo `web/index.html`
2. Agregar estructura HTML5 básica (<!DOCTYPE>, html, head, body)
3. Configurar charset UTF-8
4. Agregar título de página
5. Incluir elemento con el mensaje "Hola multiagentes"

**Criterios de aceptación**:
- Archivo HTML válido
- Mensaje visible en el documento

---

### Tarea 2: Aplicar estilos CSS
**Descripción**: Centrar el mensaje y aplicar estilos básicos
**Tiempo estimado**: 10 minutos
**Responsable**: Agente Desarrollador
**Depende de**: Tarea 1

**Subtareas**:
1. Agregar elemento `<style>` en el `<head>`
2. Aplicar flexbox para centrado vertical y horizontal
3. Configurar fuente grande y legible
4. Establecer colores con buen contraste

**Criterios de aceptación**:
- Texto centrado en pantalla
- Fuente grande (>30px)
- Buen contraste de colores
- Responsive (funciona en cualquier tamaño)
